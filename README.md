# Sonic Search — AI Mission Sessions

## Run locally
1. Install Python 3.10+.
2. Extract the ZIP and open a terminal in `sonic_search_ai`.
3. Install: `python -m pip install -r requirements.txt`
4. Launch: `python -m streamlit run app.py`
5. Open the local URL printed in the terminal (usually http://localhost:8501).

## Included
- Music-inspired dark neon mission UI and briefing screen
- Optional uploaded MP3/WAV soundtrack
- Three separate difficulty banks: Easy, Medium, Hard — 50 questions each (150 total)
- Select a difficulty, then play a randomized 10-question sprint or the full 50-question bank
- Topic filter, hints, instant explanations, progress, elapsed time, final score and answer review

## Syllabus coverage
Question topics follow the assignment sheet and uploaded DSC401-6 lecture materials: AI foundations/applications and Turing Test; rational agents; agents and environments; production systems; problem formulation and state spaces; problem characteristics and search-program design; BFS, DFS, iterative deepening, uniform-cost search; heuristic/best-first search; A*; hill climbing and variations; CSP; means-end analysis.

## Important
The banks are drafted from the provided syllabus/lecture decks and should be reviewed against the exact lecturer wording before final submission. The soundtrack is optional; browsers may not autoplay audio.
